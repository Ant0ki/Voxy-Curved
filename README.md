# Voxy Curve

A client-side Fabric addon for [Voxy](https://modrinth.com/mod/voxy) that bends the farthest LOD terrain downward, giving the world a curved, planet-like horizon.

> Minecraft **26.2** · Fabric · MIT license

## Features

- Curved horizon on Voxy's distant LOD terrain
- **Curved distance** slider (1-100%, default 10%): the share of your Voxy render distance that curves, counted from the far edge inward
- **Edge drop** (0-2000 blocks, default 300): how far the outermost edge is lowered
- Live settings, no restart needed
- Settings tab inside Sodium's Video Settings
- Client-side only, no network access

## Requirements

- Minecraft 26.2 with [Fabric Loader](https://fabricmc.net/)
- [Voxy](https://modrinth.com/mod/voxy)
- [Sodium](https://modrinth.com/mod/sodium) (provides the settings screen)

## Installation

Download the jar from the [Modrinth page](https://modrinth.com/mod/world-curvature-mod-for-voxy) or the Releases tab and put it in your `mods` folder next to Voxy and Sodium.

## Building

Requires JDK 25.
